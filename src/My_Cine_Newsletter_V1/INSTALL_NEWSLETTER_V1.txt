IMPORTANT SECURITY
The Client Secret and authorization code previously pasted into chat must not
be used. Rotate/regenerate the Client Secret and generate a fresh authorization
code. Never put secrets in App.jsx, GitHub, .env committed to Git, or chat.

GET THE REFRESH TOKEN
1. Generate a FRESH Zoho authorization code using the exact Redirect URI
   registered in the Zoho API Console.

Recommended authorization URL pattern:
https://accounts.zoho.com/oauth/v2/auth?scope=ZohoCampaigns.contact.UPDATE&client_id=YOUR_CLIENT_ID&response_type=code&access_type=offline&redirect_uri=https%3A%2F%2Fmycine.netlify.app&prompt=consent

2. In the VS Code terminal, from the project root, run:

node scripts/get-zoho-refresh-token.mjs

3. Enter the Client ID, NEW Client Secret, fresh authorization code and exact
   Redirect URI when asked.

4. Copy only the returned refresh token into Netlify:
   ZOHO_REFRESH_TOKEN

5. Trigger a new Netlify deploy after changing environment variables.
