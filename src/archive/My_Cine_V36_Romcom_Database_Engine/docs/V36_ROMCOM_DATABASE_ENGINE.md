# My Ciné V36 — Romcom Database Engine

Source of truth:
- My_Cine_Romcom_Database_v1.xlsx
- 100 permanent Canon titles
- rolling 2024–2026 new-arrival candidates

Selection model:
1. Tonight's Pick from editorial new arrivals, prioritizing 2026, then 2025, then 2024
2. Crowd Favorite
3. Classic Choice
4. Passport Pick
5. Hidden Discovery
6. Critics' Choice
7. Curator's Surprise

Hard constraints:
- Live TMDB score >= 7.5
- no current-session repeats
- maximum two titles per country
- maximum two per decade
- maximum two classics
- normally maximum one East Asian title
- Movie/TV balance when Both is selected
