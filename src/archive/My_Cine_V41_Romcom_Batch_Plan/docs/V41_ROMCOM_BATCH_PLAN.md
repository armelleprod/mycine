# V41 Romcom Batch Plan

The Romcom engine now resolves the My Ciné Database once and pre-composes up to
seven non-overlapping batches. Start Fresh and Keep Exploring only advance the
saved batch cursor.

This removes live reassembly from the buttons.

Guarantees:
- no title repeats across prepared batches
- exactly seven unique titles per batch
- maximum one classic in recovery mode
- current-year, previous-year and two-year hero priority
- modern Canon fallback
- session-cached plan for instant later batches
