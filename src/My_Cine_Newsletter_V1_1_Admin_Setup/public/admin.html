Connect The My Ciné Letter

This one-time setup authorizes the Netlify Function to add confirmed subscribers to your Zoho Campaigns mailing list.

  1. In Zoho API Console, add this exact redirect URI:
    https://mycine.netlify.app/.netlify/functions/zoho-auth
  2. In Netlify, add ZOHO_CLIENT_ID and ZOHO_CLIENT_SECRET with Functions scope.
  3. Click the gold button and approve access in Zoho.
  4. Copy the refresh token shown after authorization into Netlify as ZOHO_REFRESH_TOKEN.
  5. Trigger a new Netlify deployment.
