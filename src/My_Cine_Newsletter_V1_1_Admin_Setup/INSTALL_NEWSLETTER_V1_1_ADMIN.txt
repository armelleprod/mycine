MY CINÉ NEWSLETTER V1.1
ONE-CLICK ZOHO OAUTH SETUP

COPY THESE FILES/FOLDERS INTO THE EXISTING PROJECT:
src/App.jsx
netlify/functions/zoho-subscribe.mjs
netlify/functions/zoho-auth.mjs
public/admin.html

OPTIONAL:
scripts/get-zoho-refresh-token.mjs
The admin page replaces the need to use this script manually.

DO NOT REPLACE THE COMPLETE src FOLDER.
DO NOT MODIFY ANY GENRE, TV OR MOOD DATABASE FILE.

IMPORTANT LIMITATION:
The admin callback can securely exchange the Zoho authorization code and show
the refresh token. A website cannot silently rewrite its own protected Netlify
environment variables without a separate Netlify management token. Therefore,
you must copy the refresh token once into Netlify. After that, OAuth renewal is
automatic.

STEP 1 — ROTATE THE CLIENT SECRET
Any Zoho Client Secret pasted into chat or shown in screenshots must be
regenerated before use.

STEP 2 — ZOHO REDIRECT URI
In Zoho API Console, add this EXACT Authorized Redirect URI:

https://mycine.netlify.app/.netlify/functions/zoho-auth

The protocol, domain, path, capitalization and trailing slash must match.
Use no trailing slash.

STEP 3 — NETLIFY ENVIRONMENT VARIABLES
In the My Ciné Netlify project:
Project configuration → Environment variables

Add with Functions scope and mark as secret:

ZOHO_CLIENT_ID
ZOHO_CLIENT_SECRET
ZOHO_MYCINE_LIST_KEY

Do not add ZOHO_REFRESH_TOKEN yet.

Optional:
ZOHO_ACCOUNTS_DOMAIN=https://accounts.zoho.com
ZOHO_CAMPAIGNS_DOMAIN=https://campaigns.zoho.com
ZOHO_REDIRECT_URI=https://mycine.netlify.app/.netlify/functions/zoho-auth
MYCINE_ALLOWED_ORIGIN=https://mycine.netlify.app

STEP 4 — PUSH THE PACKAGE
cd "C:\Users\ac\Dropbox\MY CINE App\mycine-netlify\mycine"
npm run build
git add src/App.jsx netlify/functions/zoho-subscribe.mjs netlify/functions/zoho-auth.mjs public/admin.html
git commit -m "Add My Cine Newsletter OAuth setup"
git push

Wait for Netlify deployment to finish.

STEP 5 — OPEN THE PRIVATE SETUP PAGE
Open:

https://mycine.netlify.app/admin.html

Click:
Connect Zoho Campaigns

Approve access in Zoho.

STEP 6 — COPY THE REFRESH TOKEN
After authorization, My Ciné displays the refresh token once.

Copy it directly into Netlify as:

ZOHO_REFRESH_TOKEN

Functions scope
Secret value

Do not paste it into chat, GitHub, email or screenshots.

STEP 7 — REDEPLOY
Trigger a new Netlify deployment after adding ZOHO_REFRESH_TOKEN.

STEP 8 — TEST THE NEWSLETTER
1. Open the live app.
2. Reach Batch 3.
3. Wait approximately two seconds.
4. Enter a test email.
5. The app should show success only after Zoho accepts the request.
6. Check the inbox for Zoho's confirmation email.
7. Confirm the subscription.
8. Verify the contact inside Zoho Campaigns → My Ciné.

RESET THE POPUP WITHOUT USING CONSOLE
Chrome DevTools:
Application → Local storage → https://mycine.netlify.app

Delete only:
mycine-letter-subscribed
mycine-letter-dismissed-at

Refresh the page.

SECURITY AFTER SETUP
The admin page contains no secrets. It only starts OAuth.
The refresh token page is generated by the secure Netlify Function.
You may delete public/admin.html after setup if desired. The OAuth callback
function can remain because it contains no credentials in source code.
